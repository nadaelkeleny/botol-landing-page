🥤 Botol - Responsive Landing Page

A modern and fully responsive landing page for a premium water bottle brand. The project focuses on creating a clean, attractive, and user-friendly interface using only HTML5 and CSS3.

✨ Features

- Fully Responsive Design
- Modern and Clean UI
- Hero Section
- Product Categories
- Product Gallery
- About Section
- FAQ Accordion (CSS Only)
- Contact Form
- Responsive Footer
- Smooth Hover Effects
- Flexbox & CSS Grid Layout

🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Font Awesome
- Google Fonts

📁 Project Structure

├── index.html
├── style.css
├── images/
└── README.md

📱 Responsive Design

The website is optimized for:

- Mobile Devices
- Tablets
- Desktop Screens
